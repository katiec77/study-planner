LedgerFocus — Accounting & Finance Study Planner (V1)

A streamlined, cloud-synced study and life command center built for accounting, finance, and CPA exam preparation.

✨ Key Features

CPA Exam Study Section (FAR): Dedicated daily check-in tracker and schedule for Financial Accounting & Reporting (F1–F6 blueprint areas & TBS drills) that verifies today's planned item and auto-hides completed sessions from the active view.

5 Core Syllabus Pillars: Interactive progress tracking and filtering across:

Financial Reporting

Financial Statement Analysis

IT for Controls

Audit

Taxation

Dual-Stream Academic Workspace: Separates Study & Exam Prep (readings, MCQs, confidence/mastery ratings) from Homework & Projects (deliverables with inline-editable sub-checkboxes).

Personal & Home Routines Tab: Dedicated workspace for laundry, meal prep, groceries, and errands with recurring weekly resets.

Recurring Weekly Automation: Checking off any recurring task (Daily, Weekly, or Bi-weekly) automatically schedules the next cycle with fresh, unchecked sub-tasks.

Built-In Focus Timer & Exam Countdown: Customizable target exam countdown banner and 25m / 45m / 10m study timer with daily logged minutes.

Cloud Auto-Save & Backups: Automatic persistence via Firebase Firestore alongside one-click CSV and JSON export/import.

🛠️ Tech Stack

Frontend: Single-file HTML5, Tailwind CSS, Vanilla JavaScript

Cloud Sync: Firebase Authentication (Anonymous) & Cloud Firestore

Hosting: GitHub Pages
